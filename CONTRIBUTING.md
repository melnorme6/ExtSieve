# Contributing to ExtSieve

ExtSieve is not currently accepting external contributions.

Before public contribution opens, this document will define:

- the development environment and supported SDK;
- build, formatting, and test commands;
- issue and pull-request expectations;
- platform verification requirements;
- dependency and asset review;
- contribution terms consistent with the MIT License.

Do not submit third-party code, fonts, icons, translations, or other assets without
clear provenance and compatible redistribution terms.
